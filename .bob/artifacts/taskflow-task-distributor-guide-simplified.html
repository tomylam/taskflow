Task Distributor User Guide

Getting Started

Create Your Account

  1. Click "Register" and select "Work Distributor"
  2. Enter your email and password
  3. Verify your email address
  4. Complete your profile

Posting a Task

Create New Task

  1. Click "Create Task" on your dashboard
  2. Enter task title and detailed description
  3. Select task type and subject area
  4. Specify word count or page length
  5. Set deadline (allow 2-3 days before your actual deadline)
  6. Set your budget

Upload Materials

  • Attach assignment PDF or original document
  • Upload rubric if available
  • Share any reference materials or samples
  • Include any specific formatting requirements

Task Lifecycle

Stage What Happens Your Action
PENDING_QUOTE Task is open for bids Review incoming quotes
QUOTED Provider submitted quote Accept or reject quote
IN_PROGRESS Provider is working Monitor progress via chat
SUBMITTED Work uploaded for review Review and approve or request revisions
COMPLETED Task finished Leave rating and review

Managing Quotes

Reviewing Quotes

  • View all submitted quotes on your task
  • Check provider rating and past work
  • Compare pricing and timelines
  • Read provider's cover message

Accept or Reject

  • Click "Accept" to hire the provider (task moves to IN_PROGRESS)
  • Click "Reject" if quote doesn't meet your needs
  • Wait for more quotes if needed

Working with Your Provider

Communication

  • Use in-task chat to communicate
  • Ask clarifying questions early
  • Provide feedback on drafts promptly
  • Be clear about your expectations

Monitor Progress

  • Check task detail page for file uploads
  • Review provider's messages and updates
  • Download and check draft work

Reviewing Submitted Work

Quality Check

  1. Download the submitted file
  2. Check against requirements: format, content, length
  3. Verify correct citation style
  4. Check for plagiarism if concerned

Approve or Request Revisions

  • Click "Approve" if work meets standards
  • Click "Request Revisions" if changes needed
  • Provide clear feedback in the chat

Completing Tasks

  • Once work is approved, task moves to COMPLETED
  • Leave a rating (1-5 stars)
  • Write a brief review (optional but helpful)
  • Payment is processed automatically

Your Dashboard

Your dashboard displays:

  • Active tasks in progress
  • Tasks waiting for quote acceptance
  • Completed tasks history
  • Total spending and average provider rating

FAQ

Can I change budget or deadline after posting?

Contact support if needed - changes may confuse providers.

What if work quality is poor?

Request revisions with specific feedback. If provider can't meet standards, reject and hire someone else.

How do I prevent plagiarism?

Use plagiarism detection software and always verify work before approving.

Can I work with the same provider again?

Yes, contact them directly for future tasks.

What if provider misses deadline?

Communicate immediately via chat. Contact support if needed.
